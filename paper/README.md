# Paper

Working title: *Hanner-Hydra: Multiplication-Free Competing Kernels from Hanner Polytopes
for Time Series Classification*.

Plan: post on arXiv (cs.LG, cross-list stat.ML), then submit to *Data Mining and Knowledge
Discovery* (DMKD), the journal of Hydra, ROCKET, MultiRocket, QUANT and the bake-offs.

## Files

| File | Content |
| :--- | :--- |
| `main.tex` | Preamble, title, abstract, section includes, bibliography |
| `sections/*.tex` | One file per section; currently outlines (`\paperoutline{...}`) |
| `tables/*.tex`, `figures/*.pdf` | Generated by `experiments/paper_tables.py`; do not edit by hand |
| `references.bib` | Bibliography; entries flagged `VERIFY` still need checking |
| `literature-review.md` | Literature search and positioning (2026-11-08) |

The numbers in the outlines come from `docs/development-log.md` (sections "M2 accuracy runs",
"M2 timing endpoint", "H1 decision", "M2 secondary analyses") and the `results-v1`
release. When a number goes into the text, take it from those sources, not from the
outline.

## Building

Tables and figures come from the stored results (needs the local `results/`):

```
uv run python experiments/secondary.py all --tag m2 --timing-tag endpoint
uv run --extra aeon python experiments/paper_tables.py --tag m2 --timing-tag endpoint --memory-tag endpoint
```

The outputs are committed, so the paper builds without the data. Then either:

- `brew install tectonic`, then `cd paper && tectonic main.tex` (tested with 0.17.0), or
- a TeX Live installation: `cd paper && latexmk -pdf main.tex`, or
- upload the folder to Overleaf.

Build output is git-ignored (`paper/.gitignore`).

## Template

The source uses the plain `article` class with `natbib` (`plainnat`), which arXiv compiles
as is. For the DMKD submission, switch to Springer Nature's `sn-jnl` class (LaTeX template
v3.1, from Springer's author pages or Overleaf) and its reference style. Only `main.tex`
should need to change: keep class-specific macros out of `sections/`.
